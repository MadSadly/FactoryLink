Factory-Link — 작업 정리 (2026-03-29 기준)
================================================================================

본 문서는 대화·구현을 통해 진행된 작업을 요약합니다. (클라이언트 UI 대규모 리팩터는
요청 범위 밖이면 제외하고, 실제 반영된 변경 위주로 기술합니다.)


--------------------------------------------------------------------------------
1. 데이터베이스 (MariaDB)
--------------------------------------------------------------------------------
- /db/schema.sql, /db/seed.sql 추가
  · companies, users, parts, chat_rooms, chat_messages, contracts
  · 시드: 회사 10곳, 부품 30개, 회사당 사용자 2명, 데모 비밀번호 password123 (bcrypt)
- server-spring/src/main/resources/schema.sql 동기화


--------------------------------------------------------------------------------
2. Spring Boot (server-spring)
--------------------------------------------------------------------------------
- MyBatis: Part / Company / Contract 매퍼(XML) 및 서비스·컨트롤러
- REST API
  · GET/POST/PUT/DELETE /api/parts (목록 필터·정렬, JWT로 소유 검증)
  · GET/PUT /api/companies, GET 상세 시 부품 목록 포함
  · GET/POST/PATCH /api/contracts (AI 연동으로 계약서 본문 생성)
- 공통 응답: ApiResponse { success, data, message }, GlobalExceptionHandler
- JWT: JwtUserPrincipal, 토큰에 companyId 클레임
- Auth: users 테이블 기준 가입/로그인 (가입 시 companyId 필수)
- pom: validation, springdoc-openapi
- application.yml: DB_*, JWT_SECRET, JWT_EXPIRATION_MS, AI_SERVER_URL 등
- 기동 시 DB_USER / DB_PASS / JWT_SECRET 검증 (test 프로필 제외)
- JwtTokenProvider: 시크릿 32바이트 이상 검증
- Health: /api/health → success/data/message 형식
- CORS: CorsConfig + WebConfig (/api/**, 5173·3000·80 등)
- WebClient 대신 RestTemplate으로 AI 서버 호출


--------------------------------------------------------------------------------
3. Node 채팅 (server-node)
--------------------------------------------------------------------------------
- mysql2 풀, DB 환경 변수 필수 검증 (DB_HOST, DB_USER, DB_PASS, DB_NAME)
- REST: /api/chat/rooms/:roomId/messages, /api/chat/rooms/:userId, POST rooms
- Socket.io: join_room, send_message, leave_room → DB 저장 후 message_received 등
- CORS: 5173, 3000 + Socket 동일 정책


--------------------------------------------------------------------------------
4. Python AI (server-ai)
--------------------------------------------------------------------------------
- 기존 /analyze/parts, /contract/generate 유지
- 추가: POST /api/recommend-parts, POST /api/generate-contract
- GET /health → service: factory-link-ai
- CORS 확장 (5173, 3000, 8080 등)
- 기동 시 OPENAI_API_KEY 필수 (lifespan 검증)
- requirements: python-dotenv 등


--------------------------------------------------------------------------------
5. DevOps
